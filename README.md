# Analisis Perbandingan Penggunaan TikTok dan Instagram

## Deskripsi Proyek
Proyek ini bertujuan untuk melakukan analisis statistik terhadap penggunaan aplikasi TikTok dan Instagram.

## Dataset
Data diperoleh melalui kuesioner responden.

## Tahapan Analisis
1. Data Cleaning
2. Data Checking
3. Statistik Deskriptif
4. Exploratory Data Analysis (EDA)
5. Visualisasi Data
6. Uji Normalitas
7. Paired Sample T-Test atau Wilcoxon Signed-Rank Test

- Google Colab
